Assets folder — add images for the site

- Add high-quality images named to match the placeholders used in HTML:
  - `ai-weiwei.jpg`
  - `olafur-eliasson.jpg`
  - `yayoi-kusama.jpg`
  - `beeple.jpg`

- Keep file sizes reasonable for web (100–500 KB) and include proper attribution in the image "alt" or a caption.
- To preview images locally, put the files in the `assets/` folder at the repository root.

Notes on rights: Only use images you have rights to publish (public domain, your own photos, or licensed images). For long-term site use, include source/attribution on each artwork page.
